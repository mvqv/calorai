# Calorie Tracker — React Native (Expo)

Мобильное приложение для подсчёта калорий на React Native + Expo.

## Запуск

```bash
cd expo-app
npx expo start
```

Откройте приложение в **Expo Go** на телефоне, отсканировав QR-код.

## Экраны

- **Главная** — сводка калорий, БЖУ, вода, приёмы пищи
- **Дневник** — детальный дневник питания по приёмам пищи
- **Добавить** — поиск продуктов и добавление в дневник
- **Аналитика** — статистика калорий и веса
- **Настройки** — язык, профиль
- **Онбординг** — первичная настройка профиля

## Переводы

Поддерживаются: Русский, English, Deutsch, Español, Türkçe, Azərbaycan, 中文, 日本語, 한국어, العربية

## Технологии

- React Native 0.85 + Expo SDK 56
- React Navigation (Bottom Tabs + Stack)
- Zustand (состояние + AsyncStorage persist)
- Lucide React Native (иконки)
